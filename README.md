# FG-TIDA Theme Proposals

This is where FG-TIDA themes are proposed, discussed, and refined ahead of formal structuring into deliverables and (eventually, if needed) Working Groups.

## Why "themes" and not "Working Groups"

At this stage, FG-TIDA is intentionally keeping the process open: raising a theme does not require anyone to commit to being a chair or lead, and doesn't lock in a fixed group structure. Themes can be discussed, merged, split, or dropped freely. Formal Working Group structure, if and when it's needed, can follow later — once themes have matured into clearer, non-overlapping scopes.

## How a theme develops

**Phase 1 — Propose and discuss (Issues).** Anyone can open a theme with a click, no GitHub experience required. This is where reach matters most — the widest possible set of participants should be able to raise and shape ideas.

1. Open a new [Issue](../../issues/new/choose) using the **Theme Proposal** template.
2. Fill in what you can — it's fine if the scope or open questions are still fuzzy.
3. Add yourself as **Proposer** (this just identifies who's raising it, not a leadership commitment).
4. Use the issue thread for discussion; link related themes as they surface.

**Phase 2 — Draft a charter (Pull Request).** Once a theme has matured through discussion and someone is ready to take ownership of writing it up properly, it graduates to a `CHARTER.md` proposed via Pull Request. This gives the theme a versioned, reviewable document — closer to what will ultimately feed into FG-TIDA's deliverables. This step is optional and only happens once a theme is ready; not every theme needs to reach this stage.

## Labels

| Label | Meaning |
|---|---|
| `theme-proposal` | Applied automatically by the issue template |
| `needs-input` | Scope still fuzzy, needs more discussion |
| `overlaps` | Likely overlaps with another open theme — candidate for merging |
| `ready-for-next-call` | Mature enough to bring to the next call |
| `merged` | Folded into another theme issue |
| `parked` | No traction / deprioritized for now |
